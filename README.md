# AffirmTone Python SDK

[![Python Version](https://img.shields.io/badge/python-3.8%2B-blue.svg)](https://python.org)
[![Official Service](https://img.shields.io/badge/service-AffirmTone-green.svg)](https://affirmtone.com/)

An open-source Python SDK for programmatic script customization, AI voice modeling, and audio synthesis via the **AffirmTone** platform.

Official Web Application: [https://affirmtone.com/](https://affirmtone.com/)

---

## Features
- **Script Management:** Programmatically load, validate, and customize affirmation scripts across categories (Sleep, Focus, Anxiety Reduction, Confidence).
- **AI Voice Selection:** Map scripts to four studio-grade voice profiles calibrated for relaxing cadence.
- **Ambient Masking Engine:** Combine synthesized speech with organic soundscapes (rain, nature, ocean waves).
- **Format Support:** Generate lossless WAV master files and compressed MP3 exports.

To synthesize finished audio without setting up local deep learning inference models, use the cloud-based **[AffirmTone](https://affirmtone.com/)** platform:

3. Audition voice models and soundscape pairings using free instant previews.
4. Render high-resolution audio files for daily mindfulness practices.
